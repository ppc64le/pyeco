## Purpose: Demonstrates graph analysis, node ranking, community detection (clustering), node embedding, topology analysis, and link prediction using the scikit-network library.

### Packages used:
scikit-network
numpy
scipy

### Functionality:

- Loads and inspects graph representations (e.g., Zachary's Karate Club dataset and custom graphs).
- Computes node centrality and ranking using algorithms like PageRank and HITS.
- Performs community detection (graph clustering) using the Louvain algorithm.
- Computes low-dimensional node embeddings via Spectral embedding.
- Computes graph topological properties such as triangle counting and core decomposition.
- Evaluates link prediction on graph edge pairs using the Jaccard Index.

### How to run the example :
```
chmod +x install_test_example.sh
./install_test_example.sh
```
