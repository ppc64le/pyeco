## ✅ Program : Z3 SMT Solver Examples

### Purpose:
Demonstrates how to use z3-solver — a high-performance SMT (Satisfiability Modulo Theories) solver — to model and solve logical constraints, optimization problems, and rule-based systems.

### Packages used:
z3-solver

### Functionality:
- Checks Boolean satisfiability (SAT/UNSAT) using propositional logic formulas.
- Solves integer arithmetic constraint systems and detects unsatisfiability.
- Performs linear optimization (maximize/minimize objectives subject to constraints).
- Encodes rule-based access-control policies and validates configurations.
- Models scheduling problems with no-overlap worker constraints.
- Uses If-Then-Else (ITE) expressions and implication chains.
- Validates product feature-exclusivity rules via constraint propagation.
- Prints structured results without using a test framework.

### How to run the example :
```
chmod +x install_test_example.sh
./install_test_example.sh
```
